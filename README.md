# Steven Casteel // Central Portal 🌐

This is the repository for the root landing page of `https://stevencasteel.github.io/`.

It is styled as a unified retro terminal hub utilizing the design language, color palette, and interactive neomorphic depth of the **BOX BATTLE** arcade engine.

---

## Active Uplinks

*   **Uplink Gateway:** [stevencasteel.com](https://www.stevencasteel.com) — Main portfolio and professional archive.
*   **Node 01:** [BOX BATTLE](https://stevencasteel.github.io/boxbattle/) — Retro action platformer arena.
*   **Node 02:** [Silk](https://stevencasteel.github.io/silk/) — Canvas graphics engine/experiment.

---

## Aesthetic Architecture

*   **Design Paradigm:** Flat-neomorphic UI modeling physical arcade switches, with variable state-reactive shadows.
*   **Signal Indicators:** Color-coded hover LEDs simulating mechanical hardware (Green, Yellow, and Red).
*   **Monitor Simulation:** Subtle, lightweight CSS-driven scanlines and luminance flickering to recreate a classic CRT screen experience.
*   **Performance Zero-Weight:** Built using pure, vanilla HTML5 and CSS3 within a single self-contained file—maximizing loading speeds with zero external asset dependencies or package layers.

---

## Updates and Maintenance

To modify this hub, update the `index.html` file directly in this repository. Push the changes to your `main` branch, and GitHub Pages will deploy the updates automatically to your root URL.
